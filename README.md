# Личный офлайн AI-ассистент по заметкам в Obsidian

Набор файлов к ролику «Личный офлайн AI-ассистент по заметкам в Obsidian». Превращает папку Markdown-заметок в векторную базу и даёт умный чат по ним. Работает на вашем компьютере: ни заметки, ни вопросы не уходят в облако.

Канал с материалами: [@ByteAutomate_AI](https://t.me/ByteAutomate_AI)

```bash
git clone https://github.com/Kavilucky/ep28-obsidian-ai
```

## Что внутри
| Файл | Для чего |
|---|---|
| `install_ollama_models.bat` / `install_ollama_models.sh` | скачивают модели `nomic-embed-text` и `qwen2.5:7b` через Ollama |
| `smart-connections-settings.json` | шаблон настроек плагина: локальный адрес `127.0.0.1:11434`, исключение тяжёлых вложений |
| `backup_vault.ps1` / `backup_vault.sh` | зашифрованный бэкап хранилища и индекса `.smart-env` по схеме 3-2-1 |
| `Инструкция.txt` | та же инструкция простым текстом |

## Как это работает
1. Плагин режет заметки на куски и просит модель `nomic-embed-text` превратить каждый кусок в вектор из 768 чисел.
2. Вопрос тоже становится вектором. Близкие по смыслу куски находятся по косинусному сходству, даже если в них нет ваших слов.
3. Найденные заметки читает локальная модель `qwen2.5:7b` и отвечает со ссылками на файлы.

## Пошаговая установка для новичка
1. **Ollama.** Скачайте с https://ollama.com/download и установите. Сервер слушает `127.0.0.1:11434`.
2. **Модели.** Запустите `install_ollama_models.bat` (Windows) или `bash install_ollama_models.sh` (Linux, macOS). Модель эмбеддингов весит около 270 МБ, чат-модель около 4,7 ГБ; для чата нужно 6-8 ГБ свободной памяти. Скачивание единственный шаг, которому нужен интернет.
3. **Плагин.** В Obsidian: Настройки, Сторонние плагины, Обзор, найдите Smart Connections, установите и включите.
4. **Настройка.** В настройках плагина выберите локального провайдера Ollama и введите значения по таблице ниже. Файл `smart-connections-settings.json` это **шаблон**: имена полей в нём подобраны по смыслу и могут отличаться в вашей версии плагина, поэтому не подменяйте им файл настроек плагина без копии.
5. **Индекс.** Дождитесь, пока плагин проиндексирует хранилище (индекс лежит в `.smart-env`). Первая индексация большого хранилища идёт долго.
6. **Чат.** Откройте боковую панель Smart Connections и задайте вопрос своими словами, например «сколько брать за час».

| Настройка | Значение |
|---|---|
| Провайдер эмбеддингов | Ollama, адрес `http://127.0.0.1:11434` |
| Модель эмбеддингов | `nomic-embed-text` (768 измерений) |
| Чат-модель | `qwen2.5:7b` |
| Исключить папки | `attachments`, `_private`, `secrets` |
| Исключить расширения | `png jpg jpeg gif webp pdf mp3 mp4 mov zip` |
| Лимит размера файла | 512 КБ |

## Проверка офлайн-режима
Отключите сеть и задайте вопрос в чате: ответ должен прийти. Для строгой проверки смотрите монитор сети: после загрузки моделей исходящего трафика от Ollama и Obsidian быть не должно.

## Резервная копия (обязательно)
Правило 3-2-1: три копии, два носителя, один внешний диск. Запуск:

```
# Windows
powershell -ExecutionPolicy Bypass -File backup_vault.ps1 -Vault "D:\Notes" -External "E:\obsidian"

# Linux / macOS
VAULT="$HOME/Notes" EXTERNAL_DIR="/mnt/usb/obsidian" bash backup_vault.sh
```

Нужен `gpg`: он зашифрует архив (AES-256) и спросит пароль. Пароль в файлах не хранится, потеряете пароль, потеряете копию. Не удаляйте оригиналы, пока не проверили восстановление на другом компьютере.

## Честные ограничения
- Скрипты и шаблон настроек **не запускались на живом железе** автором набора; проверьте на копии хранилища.
- Скорость ответа («за две секунды» в ролике) сценарная; реальная зависит от процессора, видеокарты и размера модели.
- Цены облачных сервисов в ролике ориентировочные, проверяйте актуальные тарифы.
- Не храните пароли в заметках: для них нужен менеджер паролей. Держите индекс `.smart-env` в локальной папке, а не в открытой облачной синхронизации.
- Модели `qwen2.5:7b` и `nomic-embed-text` проверены только как рекомендация; другие не тестировались.
